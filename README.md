# جدولي الجامعي

موقع مستقل للطلاب الجامعيين: صوّر جدول محاضراتك (لقطة شاشة من بوابة الجامعة أو صورة)، راجع المحاضرات، اجعله على ذوقك، واحفظه خلفية لجوالك.

- الأيام أعمدة والساعات صفوف، وتتوقف الصفوف تلقائيًا عند آخر محاضرة.
- كل محاضرة كتلة تمتد على وقتها الفعلي، وكل مقرر بلون ثابت.
- قراءة الصور عبر القراءة الذكية (Google Gemini عبر Cloudflare Worker، انظر `worker/`)، مع إدخال يدوي عند تعذرها.
- لا تُحفظ الصور ولا الجداول في أي خادم؛ التخزين في متصفح الطالب فقط.

## التطوير

```bash
npm install
npm run dev
npm run build        # الموقع يُبنى في جذر dist/
npm test
npm run e2e
```
